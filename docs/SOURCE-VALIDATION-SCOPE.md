# Source validation scope

Frozen imported and original authority/source bytes; only new documentation additions. The expected baseline is derived from trusted Git base `cd2f8121313e99a1724274f80614926f8c1960e9` and its reviewed exact tree, not from candidate-supplied hashes. Original instructions, configuration, workflows, executable modes and source bytes remain unchanged. CI/scope authority is immutable on ordinary documentation PRs; a new product-source lane requires independent review.

The gate validates documentation/contract structure and internal links, scans complete tracked history and the effective tree with checksum-pinned Gitleaks, and proves a newly generated adjacent credential is rejected. Unknown findings and scanner errors remain fatal; no exclusions or credential exceptions are introduced.

This is source-only review evidence. It grants no model, GPU, audio, rendering, vendor security, custodian, runtime, deployment, provider-effect or production certification/authorization. Existing promotion and activation controls remain unchanged.

After proving every original blob/mode unchanged, the same source job exercises the owned loopback sidecar: real authenticated and denied HTTP requests, disabled-render/no-process behavior, bounded JSON, path/symlink confinement, argument injection, capacity/missing-engine failures, entrypoint credentials/private bind, original self-test, OpenAPI and systemd contract. Tests use temporary state and never invoke a renderer or systemd. Existing owner SaaS work is not imported or certified.
